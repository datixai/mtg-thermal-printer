What is this app? This is a companion tool for playing Momir Basic — a Magic: The Gathering format where players use only basic lands and randomly generated creature cards each turn. Enter a mana cost, press Enter, and a random card appears (or prints on the connected thermal printer). The database stores every MTG card ever printed and works completely offline after the first download.
